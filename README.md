# 🎓 Student Management System

A console-based **Student Management System** built using **Core Java and Maven**. This project demonstrates student record management using CRUD operations, file handling, input validation, exception handling, Object-Oriented Programming, and Maven project management.

---

## 📖 About the Project

The **Student Management System** is designed to manage student information through a simple console-based application.

It allows users to add, view, search, update, and delete student records. Student information is stored using Java File Handling.

This project was developed to strengthen my understanding of **Core Java**, **Object-Oriented Programming (OOP)**, **CRUD operations**, **File Handling**, **Exception Handling**, and **Maven**.

---

## ✨ Features

- 👤 Add Student
- 📋 View All Students
- 🔍 Search Student by ID
- ✏️ Update Student Details
- ❌ Delete Student
- ✅ Input Validation
- ⚠️ Exception Handling
- 📁 File-Based Data Storage
- 📦 Maven Project Management
- 🚀 JAR Packaging

---

## 🛠️ Technologies Used

- Java
- Maven
- IntelliJ IDEA
- Java Collections
- Java File Handling
- Object-Oriented Programming
